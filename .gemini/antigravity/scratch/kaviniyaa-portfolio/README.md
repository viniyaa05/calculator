## 🚀 How to View Locally
Simply double-click [`index.html`](./index.html) to open it in any web browser (Chrome, Edge, Firefox, Brave, Safari).

Or run a local development server using Python:
```bash
# In PowerShell / Command Prompt inside this directory:
python -m http.server 8000
```
Then visit `http://localhost:8000` in your browser.
